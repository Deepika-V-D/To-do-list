📝 To-Do List

A simple To-Do List application developed using Python as part of my Python Development journey.

📌 About the Project

This is a beginner-friendly, menu-driven Python project for managing daily tasks.

The application allows users to add new tasks, view their current tasks, remove a selected task, and exit the program.

✨ Features

- ➕ Add a new task
- 👀 View all tasks
- 🗑️ Remove a task
- 🔢 Select tasks using task numbers
- ❌ Exit the application
- ⚠️ Handles empty task lists and invalid choices

🛠️ Technologies Used

- Python
- Lists
- "while" loop
- "for" loop
- "if-elif-else"
- User input

▶️ How to Run

1. Clone or download this repository.
2. Open "Todolist.py".
3. Run the Python program.
4. Choose an option from the menu.
5. Add, view, or remove your tasks.

💻 How It Works

1. Add Task

Enter a task and it is added to the To-Do List.

2. View Tasks

The program displays all currently saved tasks with their task numbers.

3. Remove Task

Select the task number you want to remove.

4. Exit

Exit the To-Do List application.
